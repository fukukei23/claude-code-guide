# 22 公式ドキュメント索引 — 365ページの1行要約と新規ページ監視

> Anthropic公式ドキュメントのうち Claude Code 全ページと platform 側のLLM工学関連
> セクションを一括要約した索引。毎日の監視cronが公式サイトの新規ページを検出し、
> この章へ自動追記する。

---

## この章の使い方

1. **調べたい機能で目次から探す** — 各ページの日本語タイトルに公式リンクが付いている
2. **要約は1行だけ** — 詳細は必ず公式ページを直接開く（要約は入口・正は公式）
3. **層の対応は第21章** — プロンプト〜グラフの5層のどれに効くページかは
   [第21章 エージェント工学の階層](21-agent-engineering-layers.html) で俯瞰できる

対象範囲: `code.claude.com` の英語コンテンツ **191ページ**（言語別索引11件は対象外）+
 `platform.claude.com` のLLM工学関連7セクション **174ページ**
（APIリファレンス等の機械生成ページは対象外）。
合計 **365ページ**・最終更新 2026-09-05。

## 新規ページ監視の仕組み

公式ドキュメントは `llms.txt`（全ページの機械可読索引）を公開している。
監視cronが毎日この索引を取得して既知URLリストと差分を取り、新規ページを検出すると:

1. 新規ページをローカルに取得し、1行要約を作ってこの章の該当セクションに追記
2. `convert.py` で再ビルドしてサイト更新

仕組みの実体: `~/bin/official-docs-watch.sh`（差分検出）+ durable cron（日次発火）。
未処理の新規ページは `~/.claude/state/official-docs-monitor/pending_summaries.txt`
に蓄積されるため、要約が失敗しても翌日以降に再処理される。
