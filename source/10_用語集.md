## A

### Agent（エージェント）
Claude Codeの機能の一つ。サブエージェント（別のAIインスタンス）を起動して、独立したコンテキストでタスクを実行させる。→ [07_エージェント](07_エージェント.md)

### Auto Memory（自動メモリ）
Claude Codeが自動的に保存・読み込みするプロジェクト単位の記憶。ユーザーの好み、フィードバック、プロジェクトの状況などを記録。→ [06_メモリ](06_メモリ.md)

### Autocompact（自動コンパクション）
コンテキストが上限に近づいたとき、古い会話を自動的に要約して圧縮する機能。バッファとして33kトークンが確保されている。→ [01_基礎概念](01_基礎概念.md#autocompact)

## C

### CLAUDE.md
Claude Codeに読み込ませる指示書（Markdown形式）。3層構造: グローバル、プロジェクト、ディレクトリ。→ [08_設定ファイル](08_設定ファイル.md)

### CLI（Command Line Interface）
ターミナル上で動作するClaude Codeの形態。最も高機能。→ [01_基礎概念](01_基礎概念.md)

### Compact（コンパクション）
会話を要約して圧縮する処理。`/compact`で手動実行、または自動（Autocompact）で実行される。→ [02_コマンド一覧](02_コマンド一覧.md#compact)

### Context（コンテキスト）
Claude Codeが一度に処理できる情報の総量。システムプロンプト、ツール定義、メモリ、会話履歴等で構成される。最大200kトークン。→ [01_基礎概念](01_基礎概念.md)

### Context Window（コンテキストウィンドウ）
一度に処理できるテキストの最大量。Claude Codeでは200kトークン。

<a id="context-saturation"></a>
### コンテキスト飽和（Context Saturation）
コンテキストウィンドウ（**トークン**）が会話履歴やツール結果で満杯になり、CCが停止・またはAutocompactが強制発動する状態。バイト数ではなくトークンが上限。

- **対策**: `/clear`（文脈を捨てて完全リセット）・`/compact`（要約圧縮して継続）・`/branch`（別トピックへ分岐）
- > ⚠️ **Ctrl+C再起動では解決しない**。Ctrl+Cはプロセスを殺すだけでセッション履歴（jsonl）は残る。再起動で `/resume`（続きから）を選ぶと履歴が丸ごと再読込され、**同じ飽和状態に即復帰**する。抜けるには新規セッションで始める（resumeしない）か `/clear`。

→ 対比: [ペイロード肥大化](#payload-bloat)（byte上限） / 関連: Autocompact・Compact・Context（本ページ内） / 手順: [01_基礎概念 自動コンパクション](01_基礎概念.md#autocompact)・[02_コマンド一覧](02_コマンド一覧.md)

<a id="payload-bloat"></a>
### ペイロード肥大化（Payload Bloat）
APIへ送る**リクエスト1回あたりのデータサイズ（バイト）**が32MB上限を超え、「Request too large (max 32MB)」エラーで即座に弾かれる状態。トークンではなく**バイト**が原因。

- **主な引き金**: 大きな画像の添付・巨大ファイルの一括Read・ツール結果の山積み
- **対策**: 大きな添付や巨大Readを分割・`/clear` で会話を切り詰める
- **測定**: 正確なbyteサイズを出すコマンドはない。ただしテキスト単独では到達しない上限（32MB ≒ 約800万トークン）。**発生＝ほぼ確実に画像・PDF等の添付が原因**。トークン傾向は `/context` で間接確認

#### 画像パス貼り付けの罠（実証済・2026-06-16）

CC CLIは「`.png`/`.jpg`等で終わるパス文字」を貼ると、**強制的に画像添付に変換**する。これがペイロード肥大化の主要因。

- **❌ 効かない回避策（実験で否定）**: バッククォート `` ` `` で囲む / 通常引用 / 「パスとしてコピー」で文字として貼る / Ctrl+Shift+C → **どれも添付される**（CCが拡張子で判定、バッククォート無視）
- **❌ ドラッグ＆ドロップ**: 当然添付される
- **⭕ 確実な回避 = 画像パスを「1文字も」貼らない**:
  1. **ディレクトリだけ指定**（拡張子なし）→ CCに LS させ自分で探させる。例: `/mnt/c/.../Screenshots/ の最新を LS して Read して`
  2. **ファイル名を言葉で**（拡張子 `.png` を書かない）
  3. **そもそも見せない** → 文章だけで指示。スクショ無しでも大半の質問は成立する
- **大原則**: 画像を見せたい時だけ添付。それ以外はCCに Read/LS させる

→ 対比: [コンテキスト飽和](#context-saturation)（トークン上限） / 関連: Read・Context（本ページ内） / 詳細: [01_DECISIONS/claude-code/2026-06-16_image-path-auto-attach.md](../../01_DECISIONS/claude-code/2026-06-16_image-path-auto-attach.md)
