新規ページ監視の仕組み

公式ドキュメントは llms.txt（全ページの機械可読索引）を公開している。 監視cronが毎日この索引を取得して既知URLリストと差分変更前後の違い。git diffのように「何がどう変わったか」を示すものを取り、新規ページを検出すると:

  1. 新規ページをローカルに取得し、1行要約を作ってこの章の該当セクションに追記
  2. convert.py で再ビルドソースコードから、実行可能な完成品を組み立てることしてサイト更新

仕組みの実体: ~/bin/official-docs-watch.sh（差分検出）+ durable cron（日次発火）。 未処理の新規ページは ~/.claude/state/official-docs-monitor/pending_summaries.txt に蓄積されるため、要約が失敗しても翌日以降に再処理される。
