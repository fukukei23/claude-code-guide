# 02 コマンド一覧 — ビルトインコマンド全解説

> スラッシュ（`/`）で始まるコマンド。Claude Code本体に組み込まれている。
> プラグイン由来のスキル（`/brainstorming`等）は [03_スキルシステム](03_スキルシステム.md) を参照。

---

## セッション管理

### <a id="clear"></a>`/clear`

会話履歴を**完全にリセット**する。

- システムプロンプト・MCPツール定義・スキル・メモリは残る
- ユーザーとのやり取り（質問・回答・ツール実行結果）は全て消える
- セッション開始直後と同じ状態になる
- **使いどころ**: 長時間作業後にコンテキストが汚れた時、全く別の話題に切り替える時

### <a id="compact"></a>`/compact`

古い会話を**要約して圧縮**する（手動実行版）。

- オートコンパクションと同じ処理を手動でトリガー
- 要約が残るので文脈は保持される
- `/clear` との違い: **文脈を残すか捨てるか**

### <a id="reset"></a>`/reset`

セッションを初期状態に戻す。

- `/clear` より強力: 設定の変更も元に戻す場合がある
- 基本的には `/clear` で十分なことが多い

### <a id="exit"></a>`/exit`

Claude Codeを終了する。`Ctrl+C` でも終了可能。

---

## 情報確認

### <a id="context"></a>`/context`

現在の**コンテキスト使用量**を表示する。

- トークン消費の内訳（システム・MCP・メモリ・メッセージ等）が見える
- 各MCPサーバーのツール数とトークン消費が分かる
- **注意**: 1回の実行で約4kトークンを消費する。多用に注意

出力例:
```
Context Usage
  GLM-5.1
  58.3k/200k tokens (29%)
  MCP tools: 21.4k tokens (10.7%)
  Free space: 108.7k (54.3%)
```

### <a id="help"></a>`/help`

ヘルプメッセージを表示。利用可能なコマンド一覧が見える。

### <a id="model"></a>`/model`

現在のモデルを表示・切り替え。

- 引数なし: 現在のモデルを表示
- モデル名指定: そのモデルに切り替え（例: `/model sonnet`）
- あなたの環境: GLM-5.1がデフォルト

### <a id="cost"></a>`/cost`

セッションのコスト概算を表示。API利用料の目安。

---

## 設定

### <a id="config"></a>`/config`

設定メニューを開く。モデル・テーマ・権限等の設定を対話的に変更。

### <a id="permissions"></a>`/permissions`

権限設定を管理。ツール実行時の許可・拒否ルールを設定。

- `allow`: 自動許可（プロンプトを出さない）
- `deny`: 自動拒否
- 未設定: 毎回ユーザーに確認

### <a id="mcp"></a>`/mcp`

MCPサーバーの状態を表示。各サーバーの接続状態・ツール数が確認できる。

---

## 機能

### <a id="fast"></a>`/fast`

高速モードの切替。

- Opus使用時に高速出力（モデル自体の変更なし）
- `Ctrl+Shift+P` → "Claude: Toggle Fast Mode" でも切替可能

### <a id="review"></a>`/review`

コードレビューを実行。

- 変更されたコードを対象にレビュー
- セキュリティ・品質・ベストプラクティスをチェック

### <a id="init"></a>`/init`

プロジェクトに `CLAUDE.md` を作成。

- コードベースを分析して自動生成
- プロジェクト固有のルール・構造を記述

### <a id="memory"></a>`/memory`

メモリを管理。記憶の確認・追加・削除。

### <a id="agents"></a>`/agents`

カスタムエージェントを管理。一覧表示・作成・編集。

### <a id="skills"></a>`/skills`

スキル一覧を表示。インストール済みのスキルとその説明。

### <a id="plan-mode"></a>Plan Mode（`EnterPlanMode`）

コマンドではないが、重要な機能モード。

- Claude Codeが「計画を立ててから実装する」モードに入る
- 実際のコード変更は行わず、設計だけを提示
- ユーザーが承認（`ExitPlanMode`）してから実装開始
- **使いどころ**: 新機能追加・大規模リファクタリング等

---

## あなたの環境での使い方

| やりたいこと | コマンド |
|---|---|
| コンテキストをリセット | `/clear` |
| トークン消費を確認 | `/context` |
| モデルを確認 | `/model` |
| MCPの状態確認 | `/mcp` |
| 高速モード切替 | `/fast` |
| 設定変更 | `/config` |
